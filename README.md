## 📊 주요 프로젝트

문제 정의에서 시작해 데이터로 답을 찾는 과정을 기록했습니다.

### 1. 취업지원서비스 — 채용공고 × 기업리뷰 교차분석
구직자가 채용공고만 보고 기업을 판단해야 하는 한계에서 출발했습니다. 잡플래닛 리뷰 감성분석과 채용공고 키워드 분석을 결합해 기업별 종합 점수를 산출하고, Streamlit 대시보드로 배포했습니다.

`Python` `텍스트마이닝` `감성분석` `Streamlit` `Pandas`

🔗 [GitHub Repository](https://github.com/seulgi525/job-support-service)

### 2. 서울시 생애주기별 사회적 고립 위험지역 분석
고립·고독사 위험이 노인에게만 집중된다는 통념을 검증하기 위해, 서울 426개 행정동 전체를 청년·중장년·노년 3개 생애주기로 나눠 복합위험지수를 산출했습니다. 공간 시각화로 연령대별 정책 사각지대와 우선순위 지역을 도출했고, 서울시 빅데이터 공모전에 출품했습니다.

`Python` `공공데이터` `복합지수` `공간시각화` `Pandas`

🔗 [GitHub Repository](https://github.com/seulgi525/seoul-social-isolation)

### 3. 이커머스 고객 행동 분석 — RFM & 코호트
"성장을 위해 어떤 고객을 집중 관리해야 하는가"를 확인하기 위해 브라질 Olist 데이터(고객 93,000명)로 RFM 세그먼테이션과 월별 코호트 분석을 수행했습니다. 재구매율 0.48%라는 수치에서 플랫폼의 구조적 문제를 진단하고, 세그먼트별 맞춤 전략 3가지를 제안했습니다.

`Python` `RFM분석` `코호트분석` `Pandas` `matplotlib`

🔗 [GitHub Repository](https://github.com/seulgi525/ecommerce-customer-analysis)

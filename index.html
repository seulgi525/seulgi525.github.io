About

데이터의 전 과정을
직접 경험합니다

크롤링으로 데이터를 직접 모으고, 분석해서 인사이트를 찾고, 서비스로 배포까지 해봤습니다. 분석이 결론에서 끝나지 않고 실제로 쓰이는 형태로 만들어지는 과정을 중요하게 생각합니다.

🔍
데이터 수집 & 전처리
웹크롤링으로 직접 데이터를 수집하고, 분석 목적에 맞게 정제·구조화합니다. 여러 출처 데이터를 결합해 분석 테이블을 설계하는 과정을 중요하게 생각합니다.
📊
분석 & 시각화
수집한 데이터에서 의미 있는 패턴을 찾고, 차트와 대시보드로 전달합니다. 분석 결과보다 "왜 이런 결과가 나왔는가"를 먼저 생각합니다.
💡
비즈니스 인사이트 도출
숫자 뒤에 있는 이유를 찾고, 실제 서비스나 정책에 적용할 수 있는 제안으로 연결합니다.
🚀
서비스 구현
분석 결과를 Streamlit이나 Vercel 배포까지 연결합니다. 데이터 분석이 실제로 쓰이는 형태로 만들어지는 경험을 쌓고 있습니다.
